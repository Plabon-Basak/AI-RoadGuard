# AI RoadGuard

AI RoadGuard is a computer vision project designed to detect road users
and vehicles from images using OpenCV and YOLO.

## Current Features

- Image loading and validation using OpenCV
- Image processing and output generation
- Vehicle and object detection using YOLOv8
- Annotated detection image output
- Detection labels and confidence scores

## Technology Stack

- Python
- OpenCV 5
- Ultralytics YOLOv8
- PyTorch
